# Inventory Management API in Go

API REST para la gestión de inventario desarrollada en Go, aplicando principios de Domain-Driven Design y Clean Architecture. El sistema permite administrar productos, categorías, stock y movimientos de inventario, registrando entradas y salidas de productos de manera estructurada.

Este proyecto está orientado a demostrar buenas prácticas en desarrollo backend con Go, incluyendo arquitectura por capas, separación de dominio, persistencia con PostgreSQL, validaciones, manejo de errores, Docker y documentación para consumo de endpoints.

## Características principales

- Gestión de productos.
- Gestión de categorías.
- Control de stock.
- Registro de movimientos de inventario.
- Entradas y salidas de productos.
- Validaciones de negocio.
- Persistencia con PostgreSQL.
- API REST estructurada.
- Arquitectura basada en DDD y Clean Architecture.
- Docker y Docker Compose.

## Tecnologías usadas

- Go
- Gin
- PostgreSQL
- GORM
- Docker
- Docker Compose
- Domain-Driven Design
- Clean Architecture
